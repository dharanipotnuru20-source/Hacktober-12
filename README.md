# Voice Job Board

## About the Project
Voice Job Board is a simple web application that helps users post job opportunities online. Users can enter job details such as the job title, location, salary or daily wage, employer name, and job description.

## Features
- Post job opportunities.
- Enter job title and location.
- Add salary or daily wage details.
- Include employer name and job description.
- Simple and user-friendly interface.

## Technologies Used
- Python
- Flask
- HTML
- SQLite
- Git and GitHub

## How to Run the Project

1. Open the project folder in VS Code.
2. Activate your Python virtual environment if needed.
3. Install Flask if it is not already installed:

   ```bash
   pip install flask
   ```

4. Run the application:

   ```bash
   python tools.py
   ```

5. Open your browser and visit:

   http://127.0.0.1:5000
